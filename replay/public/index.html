CodePilot-SWE recorded run

Two ways of fixing a real GitHub issue, run on the same ten SWE-bench Lite instances from Django and SymPy. An agentic loop that explores the repository with tools, and an agentless pipeline that localises then patches in a fixed number of steps. Every step below is replayed from a run that already happened — this page makes no model call.

What this does and does not show

The agent resolved 5 of 10; the agentless baseline 1 of 10. All four instances the two disagreed on favoured the agent, and there was none the baseline resolved and the agent did not.

This is not a statistically significant result. Exact McNemar on the four discordant pairs gives two-sided p = 0.125. Ten instances cannot clear the conventional 0.05 bar even with a perfect 4–0 split, because 2 × 0.54 = 0.125 is the smallest p this design can produce. The defensible claim is directional: a consistent direction on a sample too small for a significance claim.

The sharper finding is cost. The agent cost 8.6× the baseline for 5× the resolutions — $0.45 per resolution against $0.26. Better outcomes, worse efficiency. Of the five it missed, two hit the step ceiling and three stopped by their own choice with a wrong fix: roughly half capacity, half reasoning.
